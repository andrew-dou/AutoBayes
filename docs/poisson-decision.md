# Poisson count response contract

Use pinned Bambi Poisson with log link and explicit location/group priors. Counts0..1e6 validated before casting; retain zero rows and allow all-zero data with a prior-sensitivity warning. No sigma, nu, offsets, exposure, extra dispersion or mixture component. All Poisson predictions use the existing original-input manual path so overflow and integer-generator limits are checked before drawing; this intentionally avoids relying on a second inverse link through Bambi. Return mu=exp(eta) and optional integer y. No clipping. Compare deterministic likelihood/gradient with original-input analytical references and CPU JAX, including count boundaries, groups/interactions and existing family regressions. New fits/GPU are out of scope. Preserve failed runs. Exact-head CI gates merge.
