# Frozen target specification identity

Freeze a versioned SHA256 digest after graph/design construction from effective fitted design/response/trials, ordered group coding, category metadata, canonical formula, effective centering, resolved explicit priors and family parameters. Canonical numeric values use finite float64 hex, signed zero normalized; shapes/order retained. Execution seeds/backend are excluded. Records expose only the digest, not raw rows. This is a target-specification identity, not a cryptographic signature or hash of arbitrary user graph edits. Default comparisons refuse missing identities; allow_legacy=True explicitly returns identity_status=unverified_legacy. Malformed identities and mismatched current identities always fail. No sampling or scientific acceptance-policy change. Preserve historical records unmodified.
