# Ruled out

**Status:** Active
**Last updated:** (set on first entry)

## Summary

Approaches that have been tried and killed, each with the evidence that killed it.
This is the most valuable page in the wiki: it is the one that stops an agent with
no memory of last month from proposing last month's dead end.

**Do not revisit anything on this page.** If you believe an entry deserves another
look, say so explicitly and give the reason the original evidence no longer
applies — new data, a fixed bug upstream, a changed objective. Do not simply
re-propose it.

## Detail

Each entry:

```markdown
### <approach> — ruled out YYYY-MM-DD

**Tried:** what was actually run, with the config.
**Result:** the number that killed it.
**Why it fails:** the mechanism, if known. "It did not work" is not a mechanism.
**Would reopen if:** the specific condition that would make this worth retrying,
or "nothing foreseeable".
**Evidence:** file paths, job IDs, wiki pages.
```
